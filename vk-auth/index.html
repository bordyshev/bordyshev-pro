Серверный токен VK для «Подслушано Чемской»

Авторизация идёт через официальный Authorization Code Flow VK для приложения 54572258. Одноразовый code обменивается на access token на сервере Supabase, после чего токен сразу проверяется через users.get и photos.getWallUploadServer для группы 28539565.

Получить серверный токен VK
Нажмите «Получить серверный токен VK» и подтвердите доступ.
Запрашиваемые права: photos, wall, groups, offline. После успешной проверки замените значение Supabase Secret VK_USER_TOKEN_CHEMSKOJ на выданный токен.
