Серверный токен VK для «Подслушано Чемской»

Токен создаётся через официальный Authorization Code Flow VK. Одноразовый code обменивается на access token уже на сервере Supabase и сразу проверяется на возможность загрузки фотографий в группу 28539565.

Шаг 1. Откройте авторизацию VK в новой вкладке и подтвердите доступ.
Открыть авторизацию VK
После подтверждения VK откроет служебную страницу oauth.vk.com/blank.html. Это нормально. Не закрывайте её сразу.
Шаг 2. Скопируйте полный адрес из адресной строки страницы VK и вставьте сюда. В нём находятся только одноразовые code и state.
Шаг 3. Серверная проверка пройдена. Скопируйте токен и замените значение VK_USER_TOKEN_CHEMSKOJ в Supabase Secrets.
Готово к авторизации. Запрашиваемые права: photos, wall, groups.
